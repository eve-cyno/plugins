# EVE-Cyno plugin index

The public list of plugins and theme packages that the EVE-Cyno desktop app can install from its Marketplace. The app installs a
plugin only when the user allows the permissions it asks for, and it runs every plugin in its own sandbox.

## Submitting

Open a pull request that adds or changes one file in `entries/` (the file name is the plugin id). The archive must be a release you
publish, linked by `https:` and named in the entry by its SHA-256 and size. See [CONTRIBUTING.md](CONTRIBUTING.md) for the steps and
[POLICY.md](POLICY.md) for the review policy.

## Review

A maintainer reviews every new plugin and every version that asks for more permissions. Revoked versions are listed in
`revoked.json`. The index keeps no accounts, install counts or ratings, and listed archives are mirrored unchanged to
`plugins.eve-cyno.dev`. The full text is in [POLICY.md](POLICY.md).

## Layout

- `entries/<id>.json`: one entry per plugin or theme package; nothing else belongs in `entries/` but an empty `.gitkeep` (check C1).
- `revoked.json`: the revocation list source (`[]` at first).
- `flags.json`: reserved (`{}`).
- `tools/`: the checks, the index build and the publishing tools.
- `vendor/eve-cyno-host/`: generated by `tools/vendor-host.mjs` from a pinned desktop commit; the app's own index modules, which the
  checks run. Never edited by hand; `node tools/vendor-host.mjs --verify` holds it to its `MANIFEST.json`. These files keep the app's
  licence (`vendor/eve-cyno-host/LICENSE`).

## Workflows

Workflows run on manual dispatch, with two exceptions: `check.yml` runs on every pull request to `main` (it reads the change and holds no secret), and a
weekly scheduled re-sign (`resign.yml`) runs when the live head is older than 30 days. The re-sign is an exception to the EVE-Cyno project rule that workflows are manual-only, for `eve-cyno/plugins` only, approved by the
owner on 2026-11-18. The signature still needs the owner's approvals of the `index` and `mirror` environments (see [docs/RUNBOOK.md](docs/RUNBOOK.md)).

## Running the checks

```sh
npm ci
npm test
```

## Private sources

A user can add another index (for example an alliance's) in the app, with the desktop app version that includes private sources.
Plugins from private sources are not reviewed by EVE-Cyno; the app names their source on every permission prompt.
